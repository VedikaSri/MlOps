Why we need Docker?
-Imagine right now Ml application is working on your macbook, but fails on another engineer laptop that runs it on a Linux/Windows server

Possible reasons of failure:
-Different Python Versions
-Different versions of scikit-learn or FastAPI
-Missing Python packages
-Different OS dependencies

Docker helps package your application code,runtime, dependencies and startup instructions into a stnadarized image

4 major requirements:
-Dockerfile- iInstructions for packaging the ML application
-Image - Packaged reusable application artifact
-Container - Running instaance of that image
-Port mapping - Makes the API inside the container accessible from your system

Commands for Dpocker:
1.docker ps -> print all running containers
2.docker ps -a -> print all active/non-active containers
3.docker build -t cse-mlops ->creates images named cse-mlops
4.docker images ->list locally available docker images
5.Start the container:
docker run -d --name iris-ml-api -p 8000:8000 cse-mlops->d for detach, nothing shows up on terminal, run on dockersdesktop only

What is CI/CD?
-CI: Continuous Integration -> Automatically validates code changes through tests and build checks
-CD: Continuous Delivery -> Keeps changes ready for release, with production release potentially requiring approval
-CD: Continuous Deployment -> Automatically releases changes to production when all required checks pass

Automated Testing
-Automated testing catches issues before a change moves to production
